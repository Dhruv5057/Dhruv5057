## About

I build **end-to-end AI products and production backends**. Each project is fully runnable, thoughtfully architected, and solves a real problem.

My work spans:
- **Generative AI & LLMs** — Local models (Whisper, Ollama), prompt engineering, fallback patterns
- **NLP & Semantic Search** — Embeddings, RAG, semantic similarity-based routing
- **Backend Systems** — REST APIs, authentication, atomic transactions, audit logging
- **Full-Stack Products** — UI + backend + database in cohesive systems

I prefer **local-first AI** (privacy, cost), **practical solutions** (not toy examples), and **production patterns** (error handling, security, idempotency).
